 Сайт Вкусные рецепты

Дипломный проект — веб-сайт для публикации кулинарных рецептов.

 Функционал
- Регистрация и авторизация (JWT)
- Создание и редактирование рецептов (только автор)
- Система закладок
- Жалобы на контент
- Админ-панель для модерации
- Загрузка изображений (multer)

 Стек
- **Backend:** Node.js, Express, MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Аутентификация:** JWT, bcrypt
- **Загрузка файлов:** multer

 Установка
```bash
git clone https://github.com/Varya-rgb/recipe2.git
cd recipe2
npm install
# Настрой БД в config
